# Альфа-Холод — сайт промышленного холодильного оборудования

Статический сайт без сборки и зависимостей: чистый HTML, CSS и JavaScript.
Заявки с форм отправляются на почту через сервис Web3Forms — сайт можно размещать
на GitHub Pages без серверной части. Для просмотра достаточно открыть `index.html`
или запустить локальный сервер.

## Быстрый запуск

**Windows:** дважды кликните `start-website.cmd` — откроется браузер и локальный сервер на `http://localhost:8123`.

Вручную:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\serve.ps1 -Port 8123
```

Остановить сервер — `Ctrl+C` в окне консоли.

Сайт также работает при открытии `index.html` двойным кликом (без сервера), но локальный сервер надёжнее: корректно отдаёт SVG, JS и кириллицу.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него все файлы сайта (папка `tools` и `send.php`
   для GitHub Pages не обязательны).
2. В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch**,
   выберите ветку `main` и папку `/ (root)`.
3. Через минуту сайт откроется по адресу `https://имя-пользователя.github.io/имя-репозитория/`.
4. Отправьте тестовую заявку и проверьте, что письмо пришло (см. ниже).

Файл `.nojekyll` уже добавлен — он отключает обработку сайта Jekyll и сохраняет
структуру папок без изменений.

## Структура

```
index.html          Главная: hero, каталог, услуги, этапы, проекты, FAQ, заявка
catalog.html        Каталог: фильтры по категории и температуре, поиск, сортировка

services.html       Услуги: проектирование, монтаж, сервис, тарифы
about.html          О компании: цифры, принципы, история
contacts.html       Контакты, форма заявки, реквизиты, схема проезда

css/style.css       Вся вёрстка и дизайн-система (токены, компоненты, адаптив)
js/data.js          Категории, товары, характеристики и данные компании
js/app.js           Меню, фильтры, поиск, сортировка, карточка товара, формы, анимации

start-website.cmd   Запуск сервера и открытие сайта в браузере
```

## Где что менять

### Товары и цены

Всё в `js/data.js`:

- `CATEGORIES` — категории каталога (название, картинка, описание);
- `PRODUCTS` — товары. Чтобы добавить позицию, скопируйте объект и поменяйте поля:
  `id`, `name`, `category`, `temp`, `tempGroup`, `price`, `short`, `features`, `specs`, `image`.
  Карточка товара и фильтры обновятся автоматически.
- `TEMP_GROUPS` — температурные группы для фильтра.

Цена указывается числом в рублях (например, `89500`), форматирование — автоматическое.

### Контакты и реквизиты

`js/data.js` → объект `COMPANY`: телефон, e-mail, адрес, часы работы.

Телефон и адрес продублированы в шапке и футере каждой HTML-страницы — при изменении
контактов обновите их во всех шести файлах (`index`, `catalog`, `product`, `services`,
`about`, `contacts`). Ссылки `tel:` и адрес электронной почты тоже стоит проверить.

Почта также встречается в `FORM_ENDPOINT` и `action` форм, в `send.php` и README.
Проще всего заменить адрес поиском по всему проекту.

### Тексты страниц

Тексты блоков находятся прямо в соответствующих HTML-файлах. Общие шапка и футер
продублированы на каждой странице — правки нужно вносить во все копии.

### Отправка заявок на почту

Сайт рассчитан на **GitHub Pages**, где PHP не выполняется, поэтому формы отправляют
заявки через **Web3Forms** на адрес **kozimirovdima23@gmail.com**. Настройка уже
сделана в `js/data.js`:

```js
const FORM_ENDPOINT = "https://api.web3forms.com/submit";
const WEB3FORMS_KEY = "7e0d1371-6fbc-4c58-b1e2-3075aa5ce5f0";
```

Ключ не секретный — он лишь указывает, на какую почту присылать заявки, и может
лежать в открытом коде.

**Как проверить:**

1. Открыть сайт на GitHub Pages.
2. Отправить заявку с любой из трёх форм (подбор на главной, заявка на главной,
   заявка на контактах).
3. Письмо приходит за несколько секунд. Если его нет — проверьте папки «Спам»
   и «Промоакции», поиск по слову `web3forms`.

Важно:

- Бесплатный тариф — **250 заявок в месяц**. Этого хватает небольшому сайту;
  при большем потоке нужен платный план.
- Web3Forms — сторонний сервис: данные заявок проходят через него и хранятся
  у него до 3 лет. Для строгих требований к персональным данным лучше свой SMTP/CRM.
- Ключ привязан к одной почте. Чтобы сменить получателя, получите новый Access Key
  на <https://web3forms.com> и замените `WEB3FORMS_KEY` и `access_key` в HTML-формах
  (он продублирован там для работы без JavaScript).

**Если позже переедете на хостинг с PHP.** В `js/data.js` верните:

```js
const FORM_ENDPOINT = "send.php";
```

Загрузите `send.php` в корень сайта, укажите получателя в начале файла и проверьте
доставку. Запасной `action` у форм в HTML — `https://api.web3forms.com/submit`;
для работы без JavaScript его можно заменить на `send.php`.

### Как это устроено

`js/app.js` → `initForms()`: проверяет поля, блокирует кнопку на время отправки,
показывает успех или ошибку. Если отправить не удалось, в ошибке остаётся ссылка
«отправьте её письмом» — она открывает почтовый клиент с уже заполненным текстом
заявки, так что обращение не теряется. Для Web3Forms добавляются `subject`,
`from_name` и `botcheck`. Скрытое поле `_honey` отсекает спам-ботов: если оно
заполнено, форма показывает успех, но ничего не отправляет.

## Технические детали

- Шрифт Manrope подключён через Google Fonts; при публикации без внешних запросов
  шрифт можно положить локально в `assets/fonts`.
- Адаптив: контрольные точки 1200, 1024, 900 и 640 px; мобильное меню — бургер.
- Анимации появления отключаются при `prefers-reduced-motion: reduce`.
- Сайт можно разместить на GitHub Pages: загрузите все файлы, кроме необязательного
  `send.php`. Для хостинга с PHP переключите `FORM_ENDPOINT` на `send.php`
  (см. раздел об отправке заявок).
